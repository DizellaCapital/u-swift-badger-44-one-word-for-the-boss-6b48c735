The entry is exactly one word: **Foghorn** — the boss whose voice carries across the whole floor, announcing everything and drowning everyone else out. Funny on its own, true of a real boss habit, fresh (not a boss cliché), and it travels across any workplace. Seven bytes, a tie-break advantage.

`main.py` (stdlib only) writes the word to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (fallback `/output`), validates it (exactly one word, 1–30 characters, not only whitespace), and verifies it by read-back.
